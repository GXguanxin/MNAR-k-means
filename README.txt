This is the supplementary material for reproducing all tables and figures of the paper titled 
"MNAR-$k$-means: A $k$-means Clustering for Data Missing Not at Random with Magnitude-Decaying Probability". 

The following files are contained: 
-------
(1) initcenters_oncepkpod_functions.cpp  and  code_01_functions.R  for defining all required main functions of implementing the proposed method in R;
(2) code_02 ~ code_12 are experiments for all tables and figures of the main paper; 
(3) realdata contains two real-world datasets used in the main paper. 
-------

The R version 4.1.3 is used.
